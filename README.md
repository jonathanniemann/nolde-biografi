# Emil Nolde – en biografi

Hjemmeside for Allan Jensens biografi om den tyske ekspressionistiske maler Emil Nolde – den første komplette biografi om Nolde på dansk.

**Læs siden her:** https://nolde-biografi.dk

## Om sitet

En enkel statisk hjemmeside i ren HTML og CSS, udgivet med GitHub Pages.

- `index.html` – forside
- `kapitler/` – kapiteloversigt og en side for hvert kapitel
- `om-biografien.html`, `om-forfatteren.html`, `koeb-bogen.html`
- `assets/css/style.css` – styling
- `assets/images/` – billeder
- `assets/pdf/` – kapitler, der kan læses som PDF
- `404.html` – vises, når en side ikke findes (fx gamle links fra den tidligere hjemmeside)

## Kapitler som PDF

Indtil videre kan prologen og forordet læses som PDF. Flere kapitler kommer løbende.
